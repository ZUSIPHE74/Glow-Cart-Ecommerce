API Reference Docs

Welcome to the GlowCart RESTful API reference documentation. These endpoints allow developers, integration clients, and evaluation systems to query stores, products, reviews, and create resources programmatically.

Authentication

Write operations (POST, PUT, PATCH, DELETE) and certain restricted query routes require HTTP Basic Authentication or Session Authentication. Include the standard Authorization: Basic <credentials> header in your client requests.

Available Endpoints

GET /api/get/stores/
Access: Public

Retrieve a list of all active stores in the database. Filter by vendor owner using the query parameter.

Query Parameter: ?vendor_id=<int> (Optional)
GET /api/get/stores/vendor/<vendor_id>/
Access: Public

Retrieve all specific store locations listed under a target vendor account identifier.

GET /api/get/products/store/<store_id>/
Access: Public

Retrieve all items, inventory quantities, and detailed specifications associated with a specific store location.

POST /api/post/store/
Access: Auth Vendors

Allows a registered vendor to configure and open a new storefront. The request owner field must match the authenticated credentials.

Request Body (JSON):
{ "name": "Boutique Collection", "description": "Custom apparel", "vendor": 1 }
POST /api/post/product/
Access: Auth Store Owners

Allows vendors to publish new items on active store catalogs they own. Checks ownership validations before catalog entry.

Request Body (JSON):
{ "store": 1, "name": "Luxury Silk Ties", "description": "100% silk ties", "price": "45.00", "stock_quantity": 50, "category": "fashion", "condition": "new" }
GET /api/get/reviews/
Access: Auth Users

Retrieve comments, verification badges, and product feedback ratings.

Query Parameters (Use either): ?product_id=<int> OR ?store_id=<int>
